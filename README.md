# Swift Learning Projects

A collection of beginner-friendly iOS projects built with **Swift** and **UIKit** while learning iOS application development.

This repository contains small practice projects created to explore the fundamentals of Swift, Xcode, UIKit, and building iOS applications.

## Projects

| Project | Description |
|---|---|
| Dice | A simple dice-rolling app with randomized dice images and sound playback |
| 8Ball | A practice project for building a Magic 8 Ball-style application |
| EggTimer | An egg timer practice project |
| Xylophone | A musical keyboard practice project |

> **Note:** This repository is a work in progress. Some projects are incomplete learning exercises and may not yet implement all their intended functionality.

## Technologies

- Swift
- UIKit
- Xcode
- Interface Builder
- Storyboards

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Arshia-Moghbel/Swift-Learning-Projects.git
   ```

2. Open the desired `.xcodeproj` file in Xcode.
3. Select an available iOS Simulator or connected device.
4. Build and run the project.

## Purpose

The goal of this repository is to document my learning progress in Swift and iOS development through practical exercises and small applications.
